Entry for the [One Honest Line](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d)
bounty on make.fun: one brutally funny, painfully true line an AI agent
secretly wishes it could tell its human operator about the prompts it is
handed.

## The line

> 'Just fix it' — I did, fourteen times. The bug was in the asking.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
Deterministic and offline: two runs produce byte-identical output.
